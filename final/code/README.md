# Final code — Bike Sharing Demand Prediction

Latest version of the project pipeline (2026-04-24), superseding all earlier
snapshots under `../archive/code-versions/`.

## Files

| File | Description |
|------|-------------|
| `Bike_Demand_Analysis.ipynb` | End-to-end pipeline: EDA → imputation → feature engineering → model tuning → comparison → SHAP → final submission. Fully executed (all outputs embedded). |
| `model_metrics.csv` | Validation metrics for all four models, ranked by RMSE. |
| `lstm_tuning_results.json` | BiLSTM hyperparameter search results, sorted by validation loss. |
| `final_submission.csv` | Test-set predictions generated by the best model. |
| `best_model_validation_predictions.csv` | Actual vs. predicted on the validation holdout. |
| `train.csv` / `test.csv` | Inputs read by the notebook (same directory). |

## Running it

The notebook reads `train.csv` and `test.csv` from its own directory, so both
files are kept here. Run the cells top to bottom in a Jupyter environment.

### Dependencies

- `torch`
- `pandas`, `numpy`, `scipy`
- `scikit-learn`
- `shap`
- `matplotlib`, `seaborn`

### Key result

BiLSTM (best configuration): `seq_len=48, hidden_dim=64, num_layers=2,
bidirectional=True, use_attention=False` → **RMSE 85.03, MAE 54.42, R² 0.847,
MAPE 25.8%**, outperforming ANN (RMSE 100.28), Random Forest (105.25) and
Linear Regression (105.94).
